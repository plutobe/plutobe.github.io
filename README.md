# plutobe.github.io

Personal homepage of a software engineer.

## Tech Stack

- Pure HTML/CSS/JS
- [Anime.js](https://animejs.com/) for animations
- Canvas-based fluid simulation background

## Features

- Responsive design
- Animated entry page with SVG wave transition
- Interactive fluid dynamics background
- Social links: WeChat, GitHub, Twitter, Email

## Development

```bash
# Open directly in browser
open index.html
```

## Project Structure

```
├── index.html          # Main entry
├── css/
│   └── style.css       # Styles
├── js/
│   ├── main.js         # Core logic
│   ├── background.js   # Fluid simulation
│   └── log.min.js      # Analytics
└── assets/
    ├── avatar.jpg      # Profile photo
    ├── wechat.jpg      # WeChat QR code
    └── background.png  # Background image
```
